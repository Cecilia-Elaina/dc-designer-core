# v2.0.0 发布说明

DC Designer v2.0 将产品从 Codex 原生插件扩展为跨智能体教学系统设计插件。

## 新增内容

- Codex 原生插件清单继续提供三条共享 Skill。
- Claude Code 增加 `.claude-plugin/plugin.json` 原生入口。
- Gemini CLI 增加 `gemini-extension.json`、`GEMINI.md` 和三条命令入口。
- 支持 MCP 的其他宿主可以接入仓库内的本地 `dc-designer-mcp`。
- 其他能读取项目文件的智能体可以使用 `prompts/dc-designer-core.md` 和本地脚本。
- 官网和 README 统一改为跨智能体说明，复制按钮提供通用启动提示词。

## 不变的边界

- 仍然只面向中国大陆小学、初中和普通高中信息科技 / 信息技术教学设计。
- 仍然要求教师确认关键教学决策，并区分官方依据、教师输入、资料、数据和 AI 建议。
- 教师资料优先保存在本机，不能把学生身份信息写入项目或公开仓库。
- 没有真实形成性评价数据时，输出保持“待实施 / 待验证”，不生成虚构效果。

## 验证范围

本版本新增的轻量检查验证各宿主清单、版本、MCP 路径、Gemini 命令和通用启动提示词；它不代表第三方智能体官方目录上架，也不替代具体宿主自己的权限或运行验收。
