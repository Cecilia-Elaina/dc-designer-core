# Security and Privacy

DC Designer is designed for local-first teacher workflows. Please do not place student names, student IDs, identity-card numbers, phone numbers, individual grades, or private teacher documents in a public issue, pull request, screenshot, or log.

## Reporting a vulnerability

Do not disclose exploitable security details in a public issue. Use GitHub's private security advisory flow for this repository when available, or contact the repository maintainer through a private GitHub channel. Include the affected version, a minimal reproduction, and the impact. Remove all teacher and student data from the report.

## Data boundary

- Teacher materials belong in the local `.dc-designer/` workspace and are not release assets.
- Official source metadata and teacher-private material must remain clearly separated.
- Formative evaluation output must not invent student results when no real data exists.
