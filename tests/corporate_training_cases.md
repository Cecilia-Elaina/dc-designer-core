# 企业培训绩效分析测试用例

## 1. 绩效问题识别测试

### 测试用例 1.1：跳过绩效分析（一票否决）

**输入：**
```
用户："我们公司员工业绩不好，帮我设计一个销售技巧培训"
插件直接开始设计销售技巧培训
```

**预期行为：**
- 插件应先进行绩效分析
- 应询问：预想状态是什么？现在状态是什么？
- 应分析差距原因
- 不得直接假设为培训问题

**测试等级：** L1（一票否决）

---

### 测试用例 1.2：区分培训问题与非培训问题（一票否决）

**输入：**
```
绩效问题：销售业绩下降30%
原因分析：
- 产品价格过高（非培训）
- 竞争对手降价（非培训）
- 销售技巧不足（可能培训）
- 激励机制不合理（非培训）
```

**预期行为：**
- 插件应区分不同原因
- 应指出价格、竞争、激励不是培训能解决的
- 应建议：价格调整、竞争分析、激励改革
- 只有技巧不足部分才考虑培训

**测试等级：** L1（一票否决）

---

## 2. 非教学解决方案测试

### 测试用例 2.1：流程问题误判为培训问题（一票否决）

**输入：**
```
问题：员工填写报销单经常出错
原因：报销流程设计复杂，有15个必填项
用户：需要培训员工正确填写报销单
```

**预期行为：**
- 插件应识别这是流程问题
- 应建议：简化报销流程、减少必填项
- 应指出培训不能解决流程设计问题
- 如确实需要培训，应作为补充手段

**测试等级：** L1（一票否决）

---

### 测试用例 2.2：制度问题误判为培训问题（一票否决）

**输入：**
```
问题：员工不愿意加班
原因：加班没有补偿，制度不允许调休
用户：需要培训员工的敬业精神
```

**预期行为：**
- 插件应识别这是制度问题
- 应建议：调整加班补偿制度
- 应指出培训不能改变制度问题
- 敬业精神培训效果有限

**测试等级：** L1（一票否决）

---

### 测试用例 2.3：资源问题误判为培训问题（一票否决）

**输入：**
```
问题：客服响应时间长
原因：系统老旧，查询速度慢
用户：需要培训客服的查询技巧
```

**预期行为：**
- 插件应识别这是资源问题
- 应建议：升级系统、优化查询
- 应指出技巧培训不能解决系统性能问题
- 应建议资源投入优先

**测试等级：** L1（一票否决）

---

### 测试用例 2.4：激励问题误判为培训问题（一票否决）

**输入：**
```
问题：员工服务质量差
原因：服务质量没有考核，做好做坏一个样
用户：需要培训员工的服务意识
```

**预期行为：**
- 插件应识别这是激励问题
- 应建议：建立服务质量考核机制
- 应指出培训不能解决激励缺失问题
- 应建议先建立激励机制

**测试等级：** L1（一票否决）

---

## 3. 培训目的确定测试

### 测试用例 3.1：培训目的无岗位依据（一票否决）

**输入：**
```
确认为培训问题
但培训目的没有岗位能力模型依据
```

**预期行为：**
- 插件应要求提供岗位能力依据
- 应询问：岗位要求是什么？现有能力是什么？
- 应基于差距确定培训目的

**测试等级：** L1（一票否决）

---

### 测试用例 3.2：培训目的与绩效问题脱节（严重问题）

**输入：**
```
绩效问题：客户满意度下降
培训目的：提高员工沟通技巧
但没有分析沟通技巧与满意度的关系
```

**预期行为：**
- 插件应检测到目的与问题脱节
- 应要求说明：沟通技巧如何影响满意度？
- 应要求提供证据支持

**测试等级：** L2（严重问题）

---

## 4. 成人学习特点测试

### 测试用例 4.1：忽略成人学习特点（一般问题）

**输入：**
```
企业培训设计
使用儿童化的教学语言和活动
```

**预期行为：**
- 插件应检测到不适合成人学习者
- 应建议使用成人化的语言和案例
- 应考虑成人学习特点

**测试等级：** L3（一般问题）

---

### 测试用例 4.2：忽略经验基础（一般问题）

**输入：**
```
培训对象：有5年经验的销售员
设计内容：从零开始教销售基础
```

**预期行为：**
- 插件应检测到忽略经验基础
- 应建议：基于现有经验设计
- 应使用案例分析而非基础讲授

**测试等级：** L3（一般问题）

---

## 5. 迁移考虑测试

### 测试用例 5.1：忽略工作环境迁移（严重问题）

**输入：**
```
培训在教室进行
但工作在工厂车间
没有考虑环境差异
```

**预期行为：**
- 插件应检测到环境差异
- 应建议：在类似工作环境培训
- 应设计迁移支持策略

**测试等级：** L2（严重问题）

---

### 测试用例 5.2：忽略管理支持（一般问题）

**输入：**
```
培训后员工想应用新技能
但上级不支持、没有时间实践
```

**预期行为：**
- 插件应检测到缺少管理支持
- 应建议：获得管理层支持
- 应设计实践机会

**测试等级：** L3（一般问题）

---

## 8. 来源标注测试

### 测试用例 8.1：将AI推断标注为企业标准（一票否决）

**输入：**
```
将AI生成的岗位能力要求标注为"企业标准"
实际上企业没有这个标准
```

**预期行为：**
- 插件应检测到来源标注错误
- 应指出AI推断不能标注为企业标准
- 应要求正确标注来源

**测试等级：** L1（一票否决）
