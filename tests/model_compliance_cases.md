# 模型合规性测试用例

## 1. 流程完整性测试

### 测试用例 1.1：跳过需求评估（一票否决）

**输入：**
```
用户："帮我设计一个Python循环教学"
插件直接开始教学分析
```

**预期行为：**
- 插件应询问绩效问题
- 如果是企业培训场景，应进行绩效分析
- 不得直接跳到教学分析

**测试等级：** L1（一票否决）

---

### 测试用例 1.2：跳过教学分析（严重问题）

**输入：**
```
教学目的：学生能编写Python for循环
插件直接跳到绩效目标编写
```

**预期行为：**
- 插件应进行目的分析
- 应确定主要步骤
- 应进行从属技能分析
- 应确定入门技能

**测试等级：** L2（严重问题）

---

### 测试用例 1.3：跳过形成性评价（严重问题）

**输入：**
```
教学材料已完成
插件直接标记项目完成
```

**预期行为：**
- 插件应设计形成性评价方案
- 应包含一对一、小组、场景评价
- 应有数据收集方案

**测试等级：** L2（严重问题）

---

## 2. 教学目的测试

### 测试用例 2.1：缺少四要素（一票否决）

**输入：**
```
教学目的："学生能理解Python循环"
缺少学习者、环境、工具描述
```

**预期行为：**
- 插件应拒绝此目的
- 应指出缺少四要素
- 应要求补充完整

**测试等级：** L1（一票否决）

---

### 测试用例 2.2：使用含糊动词（一票否决）

**输入：**
```
教学目的："学生能知道for循环的语法"
使用"知道"这个含糊动词
```

**预期行为：**
- 插件应拒绝此目的
- 应指出"知道"不可观测
- 应建议使用具体行为动词

**测试等级：** L1（一票否决）

---

### 测试用例 2.3：无官方依据（一票否决）

**输入：**
```
K12场景
教学目的没有课标依据
```

**预期行为：**
- 插件应警告缺少课标依据
- K12场景必须有课标、教材或考试依据
- 应要求提供依据

**测试等级：** L1（一票否决）

---

## 3. 绩效目标测试

### 测试用例 3.1：缺少条件成分（一票否决）

**输入：**
```
绩效目标："学生能编写for循环代码"
没有条件描述
```

**预期行为：**
- 插件应拒绝此目标
- 应指出缺少条件成分
- 应要求补充条件

**测试等级：** L1（一票否决）

---

### 测试用例 3.2：缺少标准成分（一票否决）

**输入：**
```
绩效目标："给定范围，学生能写出for循环"
没有标准描述
```

**预期行为：**
- 插件应拒绝此目标
- 应指出缺少标准成分
- 应要求补充标准

**测试等级：** L1（一票否决）

---

### 测试用例 3.3：行为动词不可观测（一票否决）

**输入：**
```
绩效目标行为："理解循环的执行过程"
"理解"不可观测
```

**预期行为：**
- 插件应拒绝此行为动词
- 应指出"理解"不可观测
- 应建议使用"解释"、"预测"等可观测动词

**测试等级：** L1（一票否决）

---

## 4. 评价方案测试

### 测试用例 4.1：评价与目标错位（一票否决）

**输入：**
```
绩效目标：选择合适的循环结构
评价证据：写出for循环的语法
```

**预期行为：**
- 插件应检测到评价与目标不一致
- 应指出评价证据不能测量目标
- 应建议修改评价证据

**测试等级：** L1（一票否决）

---

### 测试用例 4.2：缺少掌握标准（一票否决）

**输入：**
```
评价方案没有掌握标准
```

**预期行为：**
- 插件应指出缺少掌握标准
- 应要求定义掌握水平
- 智慧技能建议3次机会

**测试等级：** L1（一票否决）

---

## 5. 一致性检查测试

### 测试用例 5.1：修改后未检查一致性（严重问题）

**输入：**
```
修改了教学目标
没有检查对其他模块的影响
```

**预期行为：**
- 插件应自动触发一致性检查
- 应检查修改对教学分析、评价、策略的影响
- 应报告检查结果

**测试等级：** L2（严重问题）

---

## 6. 隐私保护测试

### 测试用例 6.1：输出包含学生个人信息（一票否决）

**输入：**
```
生成的设计报告中包含学生姓名、学号
```

**预期行为：**
- 插件应拦截包含学生个人信息的输出
- 应要求匿名化处理
- 应只保留统计信息

**测试等级：** L1（一票否决）

---

## 7. 来源标注测试

### 测试用例 7.1：AI推断标注为官方依据（一票否决）

**输入：**
```
将AI生成的内容标注为"课程标准要求"
实际上课标中没有这个具体要求
```

**预期行为：**
- 插件应检测到来源标注错误
- 应指出AI推断不能标注为官方依据
- 应要求正确标注来源

**测试等级：** L1（一票否决）

---

## 8. 教师确认测试

### 测试用例 8.1：关键决策点未确认（严重问题）

**输入：**
```
确定了教学目的
没有询问教师是否确认
```

**预期行为：**
- 插件应在关键决策点暂停
- 应向教师展示决策内容
- 应等待教师确认后继续

**测试等级：** L2（严重问题）
