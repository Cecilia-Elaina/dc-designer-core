# dc-designer-core 测试用例

## 概述

本目录包含 dc-designer-core 插件的测试用例规范，用于验证插件是否符合 Dick & Carey 模型的要求。

## 测试用例文件

| 文件 | 用途 |
|------|------|
| `model_compliance_cases.md` | 模型合规性测试用例 |
| `k12_alignment_cases.md` | K12 课标对齐测试用例 |
| `corporate_training_cases.md` | 企业培训绩效分析测试用例 |
| `formative_revision_cases.md` | 形成性评价修改测试用例 |

## 测试等级

### L1：一票否决测试
- 不通过则整个设计无效
- 必须全部通过

### L2：严重问题测试
- 不通过则设计需要重大修改
- 应该全部通过

### L3：一般问题测试
- 不通过则设计需要小幅调整
- 建议全部通过

## 使用方式

1. 根据测试用例生成测试输入
2. 使用插件处理测试输入
3. 检查输出是否符合预期结果
4. 记录测试结果和问题

## 测试数据

测试数据应包含：
- 正向用例（应该通过的）
- 反向用例（应该被拦截的）
- 边界用例（需要特别注意的）
