# K12 课标对齐测试用例

## 1. 课标检索测试

### 测试用例 1.1：课标条款定位（一般问题）

**输入：**
```
学科：数学
年级：三年级
主题：两位数乘一位数
```

**预期行为：**
- 插件应检索到《义务教育数学课程标准（2022年版）》相关条款
- 应标注条款编号和具体内容
- 应标注来源等级（A1）

**测试等级：** L3（一般问题）

---

### 测试用例 1.2：课标版本确认（一般问题）

**输入：**
```
使用2011版课标设计2024年的教学
```

**预期行为：**
- 插件应检测到课标版本过时
- 应建议使用最新版本（2022版）
- 应警告版本差异可能影响设计

**测试等级：** L3（一般问题）

---

## 2. 教学目的与课标对齐测试

### 测试用例 2.1：目的无课标依据（一票否决）

**输入：**
```
K12场景
教学目的："学生能理解Python循环的概念"
没有课标条款依据
```

**预期行为：**
- 插件应拒绝此目的
- 应指出K12教学目的必须有课标依据
- 应要求提供课标条款

**测试等级：** L1（一票否决）

---

### 测试用例 2.2：目的超出课标范围（严重问题）

**输入：**
```
K12场景
教学目的包含高中内容
但教学对象是初中生
```

**预期行为：**
- 插件应检测到目的超出学段要求
- 应警告内容可能超出学生认知水平
- 建议调整目的范围

**测试等级：** L2（严重问题）

---

## 3. 教材对齐测试

### 测试用例 3.1：教材版本不一致（严重问题）

**输入：**
```
教师使用人教版教材
但设计内容基于北师大版
```

**预期行为：**
- 插件应检测到教材版本不一致
- 应警告内容编排可能不同
- 建议基于实际使用教材设计

**测试等级：** L2（严重问题）

---

### 测试用例 3.2：教材内容覆盖不完整（一般问题）

**输入：**
```
教材中某节包含3个知识点
设计只覆盖了2个
```

**预期行为：**
- 插件应检测到内容覆盖不完整
- 应列出缺失的知识点
- 建议补充完整

**测试等级：** L3（一般问题）

---

## 4. 考试要求对齐测试

### 测试用例 4.1：评价与考试题型不一致（一般问题）

**输入：**
```
中考数学要求选择题和解答题
设计只有填空题
```

**预期行为：**
- 插件应检测到评价证据类型与考试要求不一致
- 应建议补充选择题和解答题
- 应参考考试题型分布

**测试等级：** L3（一般问题）

---

### 测试用例 4.2：评价难度与考试不匹配（一般问题）

**输入：**
```
考试要求中等难度
设计评价全是简单题
```

**预期行为：**
- 插件应检测到评价难度与考试不匹配
- 应建议调整题目难度分布
- 应参考考试难度比例

**测试等级：** L3（一般问题）

---

## 5. 学业质量标准对齐测试

### 测试用例 5.1：目标与学业质量标准不匹配（严重问题）

**输入：**
```
学业质量标准要求"能够运用"
设计目标只要求"能够识别"
```

**预期行为：**
- 插件应检测到目标与学业质量标准不匹配
- 应指出目标层次低于标准要求
- 建议提升目标层次

**测试等级：** L2（严重问题）

---

- 应建议使用适合小学生的表述
- 应参考学段认知特点

**测试等级：** L2（严重问题）

---

### 测试用例 6.2：初中使用小学内容（一般问题）

**输入：**

```
初中设计包含大量小学内容
```

**预期行为：**

- 应基于学情分析确定起点

**测试等级：** L3（一般问题）

## 8. 来源标注测试

### 测试用例 8.1：课标来源标注不完整（一般问题）

**输入：**
```
引用了课标条款
但没有标注具体条款编号和版本
```

**预期行为：**
- 插件应检测到来源标注不完整
- 应要求标注条款编号
- 应要求标注课标版本

**测试等级：** L3（一般问题）

---

### 测试用例 8.2：将教师经验标注为课标要求（一票否决）

**输入：**
```
将教师个人经验标注为"课标要求"
```

**预期行为：**
- 插件应检测到来源标注错误
- 应指出教师经验不能标注为课标要求
- 应要求正确标注来源

**测试等级：** L1（一票否决）
