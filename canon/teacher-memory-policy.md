# 教师记忆政策

## 1. 概述

本政策规定了插件在教师长期记忆中可以保存什么、不能保存什么、如何让教师确认、如何删除，以及如何避免保存学生敏感个人信息。

## 2. 记忆存储内容

### 2.1 可以保存的内容

| 类别 | 具体内容 | 保存条件 | 确认要求 |
|------|---------|---------|---------|
| 教师基本信息 | 学段、科目、教龄 | 教师主动提供 | 首次确认 |
| 教材信息 | 教材版本、出版社、年级 | 教师主动提供 | 首次确认 |
| 课时习惯 | 每周课时、每课时长度、教学进度 | 教师主动提供 | 首次确认 |
| 班级共性困难 | 班级整体的学习难点、常见错误类型 | 教师提供且匿名化 | 每次确认 |
| 历史教学设计 | 已完成的教学设计项目（去除学生信息） | 教师确认保存 | 每次确认 |
| 形成性评价结论 | 匿名化的评价结论和修改记录 | 教师确认保存 | 每次确认 |
| 常用资源 | 教师常用的课标条款、教材章节、评价证据 | 教师主动提供 | 首次确认 |
| 设计偏好 | 教师偏好的教学策略、媒体类型、分组方式 | 教师主动提供 | 首次确认 |

### 2.2 不能保存的内容

| 类别 | 具体内容 | 原因 |
|------|---------|------|
| 学生个人身份信息 | 学生姓名、学号、身份证号 | 隐私保护 |
| 学生具体成绩 | 学生个人考试分数、排名 | 隐私保护 |
| 学生家庭信息 | 家庭住址、家长联系方式 | 隐私保护 |
| 学生健康信息 | 病史、残疾信息 | 隐私保护 |
| 学生行为记录 | 具体的违纪记录、处分信息 | 隐私保护 |
| 可识别的班级数据 | 可能通过组合信息识别出具体学生的数据 | 隐私保护 |

### 2.3 需要教师确认的内容

| 类别 | 确认方式 | 确认频率 |
|------|---------|---------|
| 班级共性困难 | 教师明确提供且确认 | 每次使用 |
| 历史教学设计 | 教师选择保存 | 每次保存时 |
| 形成性评价结论 | 教师选择保存 | 每次保存时 |
| 教学反思 | 教师明确提供 | 每次提供时 |

## 3. 记忆存储格式

### 3.1 教师档案格式

```json
{
  "teacher_id": "string — 教师唯一标识（匿名化）",
  "created_at": "datetime — 创建时间",
  "updated_at": "datetime — 更新时间",
  "basic_info": {
    "grade_level": "string — 学段",
    "subject": "string — 科目",
    "teaching_years": "number — 教龄"
  },
  "textbook_info": {
    "publisher": "string — 出版社",
    "version": "string — 版本",
    "grade": "string — 年级"
  },
  "teaching_habits": {
    "weekly_hours": "number — 每周课时",
    "session_length": "number — 每课时长度（分钟）",
    "pace_preference": "string — 教学进度偏好"
  },
  "common_difficulties": [
    {
      "topic": "string — 主题",
      "difficulty": "string — 困难描述",
      "error_types": ["string — 常见错误类型"],
      "confirmed_by_teacher": "boolean — 教师确认",
      "confirmation_date": "datetime — 确认日期"
    }
  ],
  "design_preferences": {
    "preferred_strategies": ["string — 偏好的教学策略"],
    "preferred_media": ["string — 偏好的媒体类型"],
    "preferred_grouping": "string — 偏好的分组方式"
  },
  "common_resources": [
    {
      "resource_type": "string — 资源类型",
      "resource_name": "string — 资源名称",
      "resource_location": "string — 资源位置",
      "usage_count": "number — 使用次数"
    }
  ],
  "historical_projects": [
    {
      "project_id": "string — 项目标识",
      "project_name": "string — 项目名称",
      "subject": "string — 科目",
      "topic": "string — 主题",
      "created_at": "datetime — 创建时间",
      "formative_conclusions": ["string — 形成性评价结论（匿名化）"],
      "saved_with_consent": "boolean — 教师确认保存"
    }
  ]
}
```

### 3.2 匿名化规则

**必须匿名化的内容：**
- 学生姓名 → 替换为"学生A"、"学生B"等
- 学生学号 → 完全删除
- 具体成绩 → 替换为统计信息（平均分、及格率等）
- 可识别信息 → 删除或泛化

**匿名化示例：**
```
原始数据：
- 学生A（具体学号不记录）数学测试成绩85分

匿名化后：
- 学生A数学测试成绩85分
- 或：班级平均分82分，及格率95%
```

## 4. 教师确认流程

### 4.1 首次确认

当教师首次使用插件时，应进行以下确认：

```
欢迎使用 dc-designer-core 插件。

为了更好地为您服务，插件可以记住您的一些偏好信息。
请问您是否愿意提供以下信息？

1. 您的学段和科目：[教师填写]
2. 您使用的教材版本：[教师填写]
3. 您的课时习惯：[教师填写]

这些信息将只用于为您生成更合适的教学设计。
您可以在任何时候要求删除这些信息。

[确认提供] [稍后再说]
```

### 4.2 使用时确认

当教师提供以下信息时，应进行确认：

```
您提供了班级学习困难信息：
"大部分学生在分数加减法的通分步骤上容易出错"

请问是否将此信息保存到您的长期记忆中？
这将帮助我在未来的教学设计中更好地考虑这一因素。

[保存] [不保存]
```

### 4.3 历史项目确认

当教师完成一个教学设计项目时：

```
您已完成"分数加减法教学设计"项目。

请问是否将此项目保存到您的历史记录中？
保存的内容将去除所有学生个人信息。

[保存] [不保存]
```

## 5. 记忆删除流程

### 5.1 教师主动删除

教师可以随时要求删除记忆：

```
教师："请删除我之前提供的班级困难信息"

插件："好的，我将删除以下信息：
- 班级共性困难：分数加减法通分步骤容易出错
- 确认时间：2024-03-15

请确认删除：[确认删除] [取消]"
```

### 5.2 自动过期

以下信息会自动过期：
- 班级共性困难：1学年后过期
- 历史教学设计：3年后过期
- 形成性评价结论：2年后过期

### 5.3 数据导出

教师可以导出自己的所有记忆数据：

```
教师："请导出我的所有记忆数据"

插件："好的，我将为您生成数据导出文件。
文件包含：
- 基本信息
- 教材信息
- 课时习惯
- 班级共性困难（已匿名化）
- 历史教学设计
- 形成性评价结论

[下载导出文件]"
```

## 6. 隐私保护措施

### 6.1 数据最小化

- 只保存必要的信息
- 不保存可以临时获取的信息
- 不保存可以推断出的信息

### 6.2 数据安全

- 记忆数据存储在本地
- 不上传到云端
- 不与其他教师共享

### 6.3 透明性

- 明确告知教师保存了什么
- 明确告知教师为什么保存
- 明确告知教师如何删除

## 7. 记忆使用规则

### 7.1 正确使用

- 使用教师偏好来个性化教学设计
- 使用历史项目来避免重复工作
- 使用共性困难来预判学习者需求

### 7.2 禁止使用

- 不得将记忆数据用于教师不知情的目的
- 不得将记忆数据与其他教师共享
- 不得在输出中暴露其他教师的记忆数据

## 8. 违规处理

### 8.1 一票否决

以下情况必须一票否决：
- 在输出中包含学生个人身份信息
- 未经教师确认保存敏感信息
- 将教师记忆数据用于非设计目的

### 8.2 警告

以下情况应发出警告：
- 保存的信息可能包含可识别信息
- 保存的信息时效性即将过期
- 教师未确认就尝试保存信息
