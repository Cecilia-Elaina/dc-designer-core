# Dick & Carey 教学系统化设计模型规范

## 1. 模型概述

Dick & Carey 模型（第五版）是一种用于教学设计、开发、实施和评价的系统化方法模型。本插件将其内化为专业流程和质量门槛。

**模型核心特征：**
- 过程系统：每个步骤从前一步骤接收输入，对下一步骤产生输出
- 反馈循环：形成性评价数据驱动教学修改
- 理论折中：综合行为主义、认知主义、建构主义

## 2. 模型的十个组成成分

### 2.1 评价需求以确定教学目的（Assess Needs to Identify Instructional Goals）

**输入：** 绩效问题描述、组织需求、教师需求
**输出：** 教学目的陈述（四要素：学习者、行为、环境、工具）
**质量门禁：** 目的陈述必须包含四要素；必须有可追溯的依据

**关键过程：**
1. 绩效分析：预想状态 - 现在状态 = 绩效差距
2. 确定是否可通过教学解决问题
3. 明晰教学目的（梅格五步骤法）
4. 评估目的可行性

**禁止事项：**
- 禁止跳过绩效分析直接假设为培训问题
- 禁止使用"知道"、"理解"等含糊目的表述
- 禁止无依据的教学目的

### 2.2 进行教学分析（Conduct Instructional Analysis）

**输入：** 教学目的陈述
**输出：** 教学分析流图（含目的步骤、从属技能、入门技能）
**质量门禁：** 流图必须覆盖所有必要步骤；必须有从属技能分析；必须确定入门技能

**关键过程：**
1. 教学目的分类（言语信息、智慧技能、心智运动技能、态度）
2. 目的分析（确定主要步骤，产生技能流图）
3. 从属技能分析（层次法、簇分析法、综合技术）
4. 确定入门技能（虚线划分）

**质量标准：**
- 1-2小时教学：至少5步，最多15步
- 所有从属技能必须有动词描述
- 入门技能必须通过与学习者验证

### 2.3 分析学习者和环境（Analyze Learners and Contexts）

**输入：** 教学分析结果、目标人群描述
**输出：** 学习者分析报告、应用环境分析报告、学习环境分析报告
**质量门禁：** 必须覆盖八个学习者特征维度；必须分析应用环境和学习环境

**学习者分析八个维度：**
1. 入门技能
2. 对该领域已有的知识
3. 对教学内容和传递系统的态度
4. 学习动机（ARCS模型）
5. 学业能力水平
6. 学习偏好
7. 对提供教学机构的态度
8. 群体特征

**环境分析：**
- 应用环境：物理条件、社会环境、管理支持、技能相关性
- 学习环境：现状 vs 应有条件、设施匹配、模拟可行性

### 2.4 编写绩效目标（Write Performance Objectives）

**输入：** 教学分析流图、学习者分析、环境分析
**输出：** 绩效目标清单（含行为、条件、标准三成分）
**质量门禁：** 每个目标必须包含三成分；行为动词必须可观测；必须与教学分析对应

**目标三成分（梅格模型）：**
1. **行为表述**：学习者能够做什么（用具体行为动词）
2. **条件表述**：完成任务时的条件和可用资源
3. **标准表述**：判断完成情况的标准

**禁止使用的行为动词：**
- 知道、理解、了解、欣赏、掌握（含糊不可观测）
- 应使用：识别、分类、演示、生成、陈述、执行、选择

### 2.5 开发评价方案（Develop Assessment Instruments）

**输入：** 绩效目标清单
**输出：** 评价方案（入门技能测试、前测、练习测试、后测）
**质量门禁：** 评价必须与目标对齐；必须覆盖所有目标；必须有掌握标准

**四种考试类型：**
1. 入门技能测试：评定预备技能掌握情况
2. 前测：确定学习者已掌握的技能
3. 练习测试：教学中提供主动参与机会
4. 后测：测定教学目标完成情况

**四类质量评判原则：**
1. 以目标为中心：与目标中的行为、条件、标准一致
2. 以学生为中心：适合学习者词汇、经验、需求
3. 以环境为中心：与应用环境和学习环境一致
4. 以评测为中心：语法正确、指示清晰、避免偏题

### 2.6 开发教学策略（Develop Instructional Strategy）

**输入：** 前五步结果
**输出：** 教学策略文档
**质量门禁：** 必须包含五个学习成分；必须针对不同学习结果类型；必须有媒体选择说明

**五个学习成分：**
1. 教学前活动：激励、目标、预备技能
2. 内容呈现：信息、概念、规则、原理
3. 学习者参与：练习和反馈
4. 评测：入门技能测试、前测、后测
5. 增强活动：记忆辅助、迁移考虑

**针对不同学习结果的策略：**
- 智慧技能：层次结构，优先从属技能
- 言语信息：关联性，精细加工
- 运动技能：动作分解，操作反馈
- 态度：榜样力量，行为展示

### 2.7 开发和选择教学材料（Develop and Select Instructional Materials）

**输入：** 教学策略
**输出：** 教学材料包（教学材料、评测材料、课程管理信息）
**质量门禁：** 材料必须与策略一致；必须适合目标学习者；必须包含适当例子和练习

**教学包组成：**
1. 教学材料：主要目标材料、学习目标材料、增强材料
2. 评测材料：考试题、评价量表
3. 课程管理信息：教师手册

### 2.8 设计和实施形成性评价（Design and Conduct Formative Evaluation）

**输入：** 教学材料初稿
**输出：** 形成性评价数据和改进建议
**质量门禁：** 必须包含三个评价阶段；必须有数据收集方案；必须有改进建议

**三个评价阶段：**
1. 一对一评价：3个典型学习者，评估清晰度、影响力、可行性
2. 小组评价：8-20个学习者，评估教学效果和群体问题
3. 场景评价：30个学习者，评估在真实环境中的效果

### 2.9 修改教学（Revise Instruction）

**输入：** 形成性评价数据
**输出：** 修改后的教学设计
**质量门禁：** 必须基于数据分析；必须检查对其他模块的影响；必须有修改记录

**数据分析步骤：**
1. 入门技能分析
2. 教学顺序检查
3. 有问题目标的确定
4. 教学策略检查
5. 教学材料检查

### 2.10 设计和进行总结性评价（Design and Conduct Summative Evaluation）

**输入：** 修改后的教学设计
**输出：** 总结性评价报告
**质量门禁：** 必须由独立评估员执行；必须包含专家评价和实地试验

**两个阶段：**
1. 专家评价：适合度、内容、设计、可用性、当前用户
2. 实地试验：真实环境中的教学效果

## 3. 模块间依赖关系

```
教学目的 → 教学分析 → 学习者/环境分析 → 绩效目标 → 评价方案
                                                         ↓
修改教学 ← 形成性评价 ← 教学材料 ← 教学策略 ← ← ← ← ←
```

**关键依赖规则：**
- 教学分析依赖教学目的
- 绩效目标依赖教学分析和学习者分析
- 评价方案依赖绩效目标
- 教学策略依赖前五步所有结果
- 教学材料依赖教学策略
- 形成性评价依赖教学材料
- 修改教学依赖形成性评价数据

## 4. 反馈循环机制

修改教学不是终点，而是循环的第一步。修改可能影响：
- 教学分析（如果发现分析有误）
- 入门技能假设（如果假设不成立）
- 绩效目标（如果目标不合理）
- 评价方案（如果评价不恰当）
- 教学策略（如果策略无效）
- 教学材料（如果材料有缺陷）

## 5. 理论基础

### 5.1 行为主义
- 学习是响应概率的改变
- 通过观察行为得出学习是否发生
- 教学是对学生适当反应的强化

### 5.2 认知主义
- 学习在学生将新信息融入记忆时发生
- 教学指导、支持和促进学生内在心理过程
- 关注信息加工和知识结构

### 5.3 建构主义
- 学习是个性化产物
- 学生通过将新信息与已有知识结合而构建
- 教师主要作用是创建适当的学习环境
