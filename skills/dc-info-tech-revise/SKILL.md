# dc-info-tech-revise

根据教师反馈、形成性评价方案、匿名聚合数据或教师反思修改已有中国 K12 九学科教学设计。

运行：

```text
python scripts/dc_designer.py revise --project <project.json> --input-file <feedback.json> --output-dir <output-dir>
```

流程必须是：

1. 读取项目和反馈，拒绝学生姓名、学号、个人成绩等敏感信息；
2. 先生成影响分析，说明可能影响教学目的、技能图、目标、评价、策略和材料中的哪些模块；
3. 只修改教师确认采纳的模块，并保留稳定编号；
4. 重新运行图逻辑、来源、目标-评价和全项目一致性检查；
5. 保存修改记录、未解决事项和需要教师确认的事项；
6. 重新导出项目包。

没有真实形成性评价数据时，只能生成“待验证修订预案”，不得把 AI 推断写成课堂效果。

## 会话版本

修改必须在同一 `session_id` 下生成新项目版本，不得覆盖历史版本。返回当前阶段、受影响模块、前后版本、来源快照、视觉检查状态和 `can_export_final`。没有真实形成性评价数据时，保持“待实施/待验证”，不得生成效果比例或学生结果。
