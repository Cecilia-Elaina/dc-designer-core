# 普通高中九学科元数据

本目录包含教育部《普通高中课程方案和语文等学科课程标准（2017 年版 2020 年修订）》通知附件中的九个学科：

语文、数学、英语、物理、化学、生物学、历史、地理、思想政治。

文件名使用 <subject>_2017_2020.json。普通高中政治在公共界面和来源记录中称为“思想政治”；义务教育对应名称为“道德与法治”，内部适配器 ID 统一为 politics。

记录包含课程目标和核心素养候选、课程结构、内容领域、学业质量入口、评价证据和学科校验规则。条款候选仅用于定位与生成草案，教师仍需打开教育部官方附件核对具体课时要求。

官方通知和附件链接见上级目录的 source_registry.json。原始 PDF 与 OCR 缓存只保存在本机私有知识库，不随仓库发布。
