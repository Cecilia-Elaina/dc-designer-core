# 课程标准数据目录

本目录存放 dc-designer-core 插件所使用的本地课程标准数据。

## 目录结构

- **k12/** — 义务教育2022课程标准元数据，按学科索引。包含各学科的核心素养、内容领域、学业质量标准等结构化信息。
- **high_school/** — 普通高中2017/2020课程标准元数据，按学科索引。包含各学科的课程目标、内容标准等结构化信息。
- **test_fixtures/** — 仅用于单元测试的模拟数据，不代表真实课程标准内容，不得在正式业务逻辑中引用。

## 数据来源

本目录中的结构化元数据源自以下真实 PDF 文件：

- `D:\Download\教学系统设计\政策导向知识库层\01_课程标准_义务教育2022\` — 义务教育各学科课程标准（2022年版）
- `D:\Download\教学系统设计\政策导向知识库层\` 中的其他课程标准相关文件
