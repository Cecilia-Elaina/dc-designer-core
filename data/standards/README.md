# K-12 课程标准知识库

本目录是 DC Designer v3 的公开课程标准元数据层，覆盖中国小学、初中和普通高中九个学科：

语文、数学、英语、物理、化学、生物学、历史、地理，以及按学段分别命名的道德与法治 / 思想政治。

## 目录结构

- k12/：义务教育课程标准（2022 年版）九学科记录和官方来源快照。
- high_school/：普通高中课程标准（2017 年版、2020 年修订）九学科记录。
- source_registry.json：官方来源主索引、版本、适用范围和内容哈希。
- subject_registry_v3.json：九个学科包的统一适配器契约。
- test_fixtures/：仅供单元测试使用的模拟数据，不代表真实课标。

每个学科记录包含课程目标和核心素养候选、内容领域、可观察行为、评价证据、策略与材料模式、形成性反馈提示、学科安全/伦理规则和条款候选。

## 来源与版本

义务教育记录锚定教育部发布的[义务教育课程方案和课程标准（2022 年版）通知](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)。

普通高中记录锚定教育部发布的[普通高中课程方案和学科课程标准（2017 年版、2020 年修订）通知](https://www.moe.gov.cn/srcsite/A26/s8001/202006/t20200603_462199.html)及其官方附件包。

原始 PDF 和 OCR 缓存只保存在本机 .dc-designer/knowledge/official/ 私有目录，不进入公开插件包。公开记录中的 content_sha256 用于核对本机已获取的原件，private_snapshot_reference 不提供公开文件路径。

## 使用边界

- A1 官方课标可以作为教学目的和约束的候选依据，但具体课时目标仍需教师核对版本、适用学段、课题和学情。
- clause_candidate 和 normalized_summary 是定位与生成候选，不是对官方文件的逐字替代。
- 地方文件、教材和教师材料是可选扩展，不得冒充国家课标。
- 不复制商业教材全文，不收集学生个人信息，不把教师私有材料写入公开目录。

## 重新生成

在仓库根目录运行：

    python scripts/build_k12_subject_knowledge.py

脚本只生成公开 JSON 元数据；更新官方来源前，应先在本机私有知识库中获取并核对原件。
