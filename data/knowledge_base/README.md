# 知识库目录说明

本目录只保留目录说明，不承载教师运行时知识库数据。插件运行时将教师资料、索引和元数据写入用户本机的 `.dc-designer/knowledge/`，不写入插件安装目录。

## 目录结构

- **documents/** — 运行时目录，不提交教师上传的原始材料。
- **indexes/** — 运行时目录，不提交教师私有索引。

## 版权与隐私规则

- 教师个人材料的 `copyright_scope` 默认为 `teacher_private_use_only`，仅材料上传者本人可引用。
- **严禁存储学生个人信息。** 任何文档、索引或元数据中不得包含学生姓名、学号、成绩等可识别个人身份的信息。
- 教师材料在被引用生成教学设计时，应遵循引用规范，注明出处。

发布仓库不得包含 `documents/` 或 `indexes/` 下的任何文件；这些路径已由仓库忽略规则保护。
